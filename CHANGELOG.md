# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-18

### Added

#### Sora Prompts
- `cinematic-shots.md` - 25+ cinematic video prompts (establishing shots, tracking shots, dolly zooms, aerial views, time-lapses)
- `narrative-scenes.md` - 25+ story-driven prompts (drama, comedy, thriller, sci-fi, fantasy)
- `product-showcase.md` - 20+ product and commercial video prompts (tech, food, fashion, automotive, luxury)

#### Runway Prompts
- `motion-graphics.md` - 25+ motion graphics and abstract prompts (liquid animations, particle effects, geometric transformations)
- `realistic-scenes.md` - 25+ photorealistic prompts (portraits, wildlife, urban, rural, extreme weather)
- `style-transfer.md` - 20+ artistic style transfer prompts (impressionist, cyberpunk, noir, Studio Ghibli, Wes Anderson)

#### Pika Prompts
- `short-form-content.md` - 25+ social media video prompts (TikTok/Reels/Shorts style, satisfying loops)
- `animation-style.md` - 20+ animation and cartoon prompts (anime, cartoon, 3D, pixel, stop-motion)
- `effects-and-transformations.md` - 20+ video effects prompts (morphing, explosions, weather, time manipulation)

#### Kling Prompts
- `human-centric.md` - 25+ human-focused prompts (dance, sports, cooking, crafts, performances)
- `nature-and-animals.md` - 20+ nature and wildlife prompts (forests, oceans, mountains, wildlife, insects)
- `chinese-aesthetics.md` - 20+ Chinese aesthetic style prompts (水墨画, 古风建筑, 武侠, 诗词意境)

#### Guides
- `prompt-engineering.md` - Complete video prompt engineering guide
- `style-keywords.md` - 200+ style keyword reference organized by category

#### Community Files
- README.md (bilingual EN/CN)
- CONTRIBUTING.md, SECURITY.md, CODE_OF_CONDUCT.md
- GitHub Actions CI, issue templates, PR template
