# Security Policy

## Reporting a Vulnerability

This repository contains curated prompt collections. There are no software dependencies or runtime components, so traditional security vulnerabilities do not apply.

If you find:

- **Malicious content** in a prompt (e.g., prompts designed to generate harmful content)
- **Spam or abuse** in issues/PRs
- **Copyright violations** in prompt content

Please report via email to the repository maintainer. Do **not** open a public issue for security concerns.

## Scope

This is a content-only repository. We review prompts for:

- Compliance with each AI tool's content policy
- Absence of prompts designed to generate NSFW, violent, or harmful content
- Proper attribution for any referenced styles or artists

## Response Timeline

- Acknowledgment: within 48 hours
- Resolution: within 7 days for content issues
